# 微缩水境 · Aquascape Diorama

用 **Three.js（r0.160+ ESM）** 打造的「鱼缸微缩景观」生态模拟 Demo，美术风格对标《原神》（卡通硬边描边 + 辉光 + 通透感）。
**零外部资源**：所有模型程序化生成、贴图 Canvas 2D 动态绘制、音乐音效 Web Audio API 实时合成。

## 运行方式

Three.js 已内置在 `lib/` 目录（零外部网络依赖），但 ES Module 无法从 `file://` 加载，
**必须通过本地静态服务器打开**：

**方式一（最简单，推荐）**：双击项目目录下的 `start.bat`，会自动启动服务器并打开浏览器。

**方式二（手动）**，在项目目录执行任一命令：

```bash
python -m http.server 8899     # Python
node server.js 8899            # Node（项目自带，零依赖）
npx serve .                    # 需联网下载 serve 包
```

然后访问 `http://127.0.0.1:8899/`。

> - 首次进入后**点击一次页面**才会启动音乐（浏览器自动播放限制）。
> - 若之前打开过旧版本，请用 `Ctrl + F5` 强制刷新，避免浏览器缓存旧文件。
> - 页面加载失败时，右下角调试入口可用：控制台执行 `__AQUA.game` 查看运行状态。

## 系统机制

### 时间
1 秒 = 1 游戏分钟，一天 = 24 分钟。昼夜循环驱动光照、水草光合、溶氧波动与 BGM 变奏。

### 氮循环（核心）
鱼排泄 + 残饵 + 尸体分解 → **氨 NH₃** →（硝化菌，附着于火山石/陶粒/过滤棉等）→ **亚硝酸盐 NO₂⁻** → **硝酸盐 NO₃⁻** →（水草吸收 / 换水移除）。
新缸有约 2 游戏天的**养水期**，硝化菌成熟前投鱼极易氨中毒。

### 水质六项
温度（加热棒控制）、pH（沉木降 / 珊瑚骨升）、氨、亚硝酸盐、硝酸盐、溶氧（水草光合 + 气泵 + 水面波动；夜间与高温下降）、清澈度（过滤器降低浑浊）。

### 鱼类生理
每条鱼独立状态机（idle / forage / flee / hunt / court / dying / corpse）+ boids 群游：
饱食度（代谢 × 温度 × 活跃度 × 体型）、健康（毒素/饥饿）、压力（拥挤/被追/无躲避）、年龄成长（幼体→亚成体→成体）。
肉食鱼饥饿时捕食小鱼小虾；尸体不捞出会持续产氨引发连锁崩缸。

### 藻类
绿藻（草食鱼主食）/ 褐藻（新缸期，硝化成熟后消退）/ 丝状藻（高 NO₃ 爆发）/ 蓝绿藻（有毒）。
NO₃ > 40 且强光触发**藻华事件**（全缸绿水、夜间溶氧暴跌）。

### 繁殖
饱食 > 80、健康 > 90、NO₃ < 20、压力 < 20、同种成体 ≥ 2 且有产卵介质（莫斯/沉木/宽叶）→ 求偶追逐 → 产卵 → 孵化幼鱼（幼体需躲藏，否则被大鱼吃掉）。

### 评分
美观度（造景多样性与稀有度）+ 生态稳定度（水质健康天数）+ 生物多样性 → S/A/B/C，升级有全屏庆祝动效。

## 性能

- 生物上限 60、植株上限 200（藻类实例池 160）
- 同物种共享几何体与贴图；鱼群共享全局时间 uniform
- 气泡/水花粒子对象池；`devicePixelRatio` 上限 2
- 设置内提供**低配降级**开关：关闭辉光 / 焦散 / 景深 / 体积光柱，玻璃改用廉价半透明材质，像素比降至 1

## 技术要点

- 后处理链：`RenderPass → OutlinePass（暖棕细描边）→ UnrealBloomPass → 径向模糊+暗角 → OutputPass → FXAA`
  - 辉光阈值取 **1.15**（而非 0.85）：本工程未启用色调映射，卡通漫反射面亮度已达 ~0.9（线性），
    阈值过低会让底砂/水面整片起辉、画面蒙白雾。现在只有镜面高光（水面波光、金边）与自发光（水晶、荧光鱼）起辉。
- **鱼体材质必须不透明**：three 的渲染顺序为 `透射缓冲（仅不透明物体）→ 不透明 → 透射玻璃 → 透明`。
  若鱼设为 `transparent: true`，它既不在玻璃的透射采样缓冲里，又会被先绘制且写深度的玻璃剔除 → 隔玻璃看不见鱼。
  因此鱼鳍的"半透明薄膜感"改为在片元着色器中按 `aRegion` 提亮去饱和来模拟。
- 鱼体着色器全局共享一个 program（`customProgramCacheKey` 默认取 `onBeforeCompile` 源码）：
  three 会在每个材质首次使用时调用 `onBeforeCompile` 并把 uniform 记到该材质上，
  因此每条鱼仍有独立的摆尾相位/灰化/饥饿变暗，但不会每条鱼都编译一份着色器（避免首帧不显示与卡顿）。
  启动时另做一次 `renderer.compile()` 预热。
- 鱼体：环线程序化几何体 + 鱼鳍三角面合并，`MeshToonMaterial.onBeforeCompile` 注入沿体轴衰减的正弦摆尾；4 阶 `gradientMap`（DataTexture + NearestFilter）实现硬边卡通明暗
- 水面：自定义 ShaderMaterial（Gerstner 波 + Fresnel + 镜面反射 + 点击/落水同心圆涟漪）
- 焦散：Canvas 生成 Voronoi 纹理双层滚动叠加，Additive 投影缸底
- 玻璃缸：`MeshPhysicalMaterial`（transmission 0.95 / ior 1.33 / thickness），金色金属包边 + 木质台座
- BGM：五声音阶（白天 C 大调 / 夜晚 A 小调），竖琴琶音 + 弦乐 pad + 木管旋律 + 木琴，ConvolverNode 程序化混响；生态恶化时切入低沉不协和层作为"听感预警"
